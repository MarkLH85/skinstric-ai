# Skinstric AI — What I Learned

## Project Architecture
I am building a complete frontend application rather than a tutorial exercise.

## Technologies
I am using Next.js, React, TypeScript, Tailwind CSS, and React Icons.

## API Integration
The project requires communicating with two supplied backend endpoints.

## Phase 1
I will collect and validate name and location information before allowing the user to proceed.

## Phase 2
I will convert an uploaded image into Base64, send it to the supplied API, and present the returned demographic scores.

## Phase 3
I will use the device camera to capture a selfie and reuse the image-analysis workflow.

## Deployment
The completed application will be deployed to Vercel and submitted with both a live URL and project/repository URL.

## Design Process
The official Figma design is required for accurate visual implementation. Until Figma access is available, the project structure and functionality can be prepared without inventing the final visual design.
