# Skinstric AI — Lesson Notes

## Project
Frontend Simplified X Skinstric.ai

## Project Goal
Build a Skinstric AI-inspired frontend application according to the supplied technical requirements and the official Figma design once access is provided.

## Technology
- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- Vercel deployment

## Phase 1 — Initial Project Setup
- Capture name and location.
- Validate both fields.
- Store user information.
- Send name and location to the Skinstric Phase 1 API.
- Provide Back and Proceed navigation.

## Phase 2 — Upload Your Image
- Accept an image upload.
- Convert the image to Base64.
- Send the Base64 image to the Skinstric Phase 2 API.
- Display Race, Age, and Gender predictions.
- Sort scores from highest to lowest.
- Display scores to two decimal places.
- Allow the user to select their actual attribute.

## Phase 3 — Take a Selfie
- Request camera access.
- Allow the user to take a selfie.
- Reuse the Phase 2 analysis logic.
- Support laptop, tablet, and mobile layouts.

## API Endpoints

- Phase 2: https://us-central1-frontend-simplified.cloudfunctions.net/skinstricPhaseTwo
